# Promo Tracker brand assets

## Frontend

- `promo-tracker-logo.svg` — full horizontal logo master for documents and larger placements.
- `promo-tracker-icon.svg` — primary product icon used by the login screen and application shell.
- `promo-tracker-icon-compact.svg` — compact 32px-oriented icon master.
- `favicon.svg` — browser favicon master.
- `favicon-32.png` — 32px PNG browser fallback.
- `app-icon-180.png` — Apple touch icon fallback.

## Telegram

- `promo-tracker-telegram-bot.svg` / `promo-tracker-telegram-bot-1024.png` — light, icon-focused bot avatar.
- `promo-tracker-telegram-group.svg` / `promo-tracker-telegram-group-1024.png` — dark group/channel avatar from the same identity.

Both Telegram exports include generous safe-area padding for circular cropping.
